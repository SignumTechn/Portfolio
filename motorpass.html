Project 05 · Web platform

MotorPass

An automotive marketplace connecting buyers, sellers and service providers — built end to end, from data model to interface.

RoleFull-stack engineer
Timeline2025 — Active
StackNext.js · Spring Boot · PostgreSQL
motorpass.app/listings

The problem

Buying or selling a used car locally usually means scattered listings, no verification, and no easy way to loop in a trusted mechanic before money changes hands.

The solution

MotorPass brings listings, buyer-seller messaging and service-provider bookings into one platform, with structured data behind every vehicle so search and filtering are fast and accurate.

How it works

From listing to sale.

01

Listing creation

A seller submits vehicle details, photos and price through a guided form. The API validates the payload and stores it as a structured record rather than free text, which is what makes filtering reliable later.

02

Search & discovery

Buyers filter by make, price range, mileage and location. Queries run against indexed PostgreSQL columns, so results stay fast even as the listing count grows.

03

Messaging & scheduling

Once a buyer is interested, an in-app thread opens between buyer and seller, with the option to schedule a verified service provider for an inspection before purchase.

04

Transaction & handover

The listing status moves from active to pending to sold, keeping the marketplace clean and giving both parties a clear record of the deal.

Project 02 · Internal platform

Sales Automation System

A business automation platform designed to streamline sales processes, data management and reporting for a growing team.

RoleFull-stack engineer
Timeline2025
StackJava · Spring Boot · React · PostgreSQL
dashboard.internal

The problem

Sales reps were tracking leads across spreadsheets and chat threads, so deals fell through the cracks and managers had no reliable view of pipeline health.

The solution

A single system that captures leads automatically, moves them through a defined pipeline, and turns that activity into reporting the sales manager actually trusts.

How it works

From lead to closed deal.

01

Lead capture

Leads come in from web forms and manual entry, and are normalized into a single schema so duplicates and stale data don't pile up.

02

Pipeline automation

Each lead is assigned a stage. Stage changes trigger follow-up reminders and status emails automatically, instead of relying on a rep to remember.

03

Reporting

Pipeline data feeds a live dashboard — conversion rate, deal value, and rep performance — computed on the backend and rendered as charts a manager can scan in seconds.

04

Handoff

Closed-won deals push structured records downstream, so finance and delivery teams pick up clean data instead of re-entering it.

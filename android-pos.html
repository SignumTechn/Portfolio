Project 03 · Mobile

POS / Android Application

A point-of-sale system built for Android — designed for speed at the till and reliability offline.

RoleAndroid engineer
Timeline2024
StackKotlin · Android SDK · SQLite

The problem

Small retail counters needed a checkout system that stays fast and usable even when the internet connection at the till drops out mid-sale.

The solution

A native Android POS that keeps a local database of the day's transactions and inventory, syncing to the server only when a connection is available.

How it works

From scan to receipt.

01

Item entry

A cashier scans or taps items into the cart. Prices and stock counts are read from the local SQLite database first, so there's no lag waiting on a network call.

02

Checkout

The app totals the cart, applies any discounts, and records the transaction locally the moment payment is confirmed — before any sync happens.

03

Offline queueing

If there's no connection, the transaction sits in a local queue. The app keeps working exactly the same either way.

04

Background sync

Once online, queued transactions push to the server and inventory counts reconcile automatically, with conflicts flagged rather than silently overwritten.
